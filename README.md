# 时光餐厅 · 日常助手

《时光餐厅》的非官方辅助模组，提供今日待答题与答案提示、答题辅助、地鼠自动击打和收益统计。

**当前版本：1.0** · [本版下载](https://github.com/SiH-zh/shiguangcanting-helper-mod/releases/tag/v1.0.0) · [全部发行版](https://github.com/SiH-zh/shiguangcanting-helper-mod/releases) · [游戏Steam商店](https://store.steampowered.com/app/4399360/?l=schinese) · [MIT许可证中文对照](LICENSE.zh-CN.md)

## 功能

| 功能 | 使用方式 |
| --- | --- |
| 今日答题 | 查看当天尚未回答的题目及正确答案，支持自己答题或确认后自动完成剩余题目。 |
| 一键完成地鼠 | 二次确认后连续完成当天剩余次数，汇总本次实际获得的板牙和面具等奖励。 |
| 自动打地鼠 | 在自己的餐厅等待自然刷新，刷新后自动击打。 |
| 收益记录 | 按存档和日期记录实际结算收益，包含启用后手动击败的记录。 |

奖励和每日额度由原版流程处理。仅处理当天剩余题目或次数；今日收益无法追溯模组启用前缺失的记录。

## 安装与更新

1. 完整退出游戏。
2. 从本版本的发行页面下载`DailyAssistant-v版本号.zip`安装包并解压；日常使用无需下载平台自动生成的源码压缩包。
3. 将包内整个`DailyAssistant`文件夹放入游戏目录的`Mods`文件夹，最终结构应为`游戏目录\Mods\DailyAssistant\DailyAssistant.dll`。
4. 启动游戏，在主菜单的“模组”中勾选“日常助手：答题与打地鼠”。首次启用时阅读游戏显示的模组提示。
5. 进入自己的餐厅，点击右上角、“我的餐厅”左侧的助手入口。

更新时先退出游戏，备份旧模组目录，再用新版完整替换`DailyAssistant`文件夹；同一安装目录只保留一个版本，备份放在`Mods`目录之外。用户设置独立保存在`UserData\Current\DailyAssistant\state.json`，正常更新无需删除该文件。

停用时在模组列表取消勾选并完整重启游戏。更换动态库后也需完整重启，避免仍运行旧代码。旧版设置字段少，回退版本前建议备份模组自己的设置文件。


## 快速使用

打开右上角、“我的餐厅”左侧的任务手账入口，在对应页面手动启用需要的功能。

- 答题：开启“答题辅助”，选择“自己答题”或“完成剩余答题”。
- 地鼠：选择“一键完成”并确认，或开启“自动打地鼠”等待自然刷新。


此版本自动打地鼠每次启动默认关闭，答题辅助设置单独保存。

完整操作见[使用说明](DailyAssistant/使用说明.md)。
