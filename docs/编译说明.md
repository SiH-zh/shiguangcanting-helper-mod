# 编译说明

## 环境

- Windows系统，已安装《时光餐厅》。
- 系统自带的.NET Framework编译器，脚本默认使用64位4.0编译器路径。
- 游戏自身的`TimeRestaurant_Data\Managed`目录提供Unity引擎、Harmony补丁库及序列化依赖。

## 编译

在仓库根目录打开PowerShell，执行以下命令，将游戏路径替换成自己的实际路径：

```powershell
& '.\DailyAssistant\Source\编译.ps1' -GameRoot 'D:\SteamLibrary\steamapps\common\时光餐厅'
```

编译结果写入`DailyAssistant\DailyAssistant.dll`，不直接修改游戏安装目录。退出游戏后再手动安装生成的模组。

脚本通过GameRoot参数定位游戏依赖，保留历史版本原始源码及编译脚本。也可使用项目文件并显式设置GameManagedDir为游戏Managed目录，参数须包含末尾路径分隔符。

## 验证源码

`Source\验证`保留对应版本的场景、计数、输入、设置或移动补丁验证源码。主编译脚本只编译Source目录顶层文件，不会将独立验证入口编入模组。部分隔离验证需要游戏依赖或Mono.Cecil程序集分析库，应按源码中实际引用单独编译，仓库未附游戏或分析库副本。

具体已有验证结果见各版本详情；这些是原交付时的验证记录，不表示每次下载或所有游戏版本均自动复测通过。


1.2.1新增BodyTypography.cs字体初始化实现，主编译脚本会自动包含。字体初始化验证源码使用隔离的引擎替身，须仅与BodyTypography.cs单独编译，不应同时引用真实引擎程序集；其结果验证初始化政策，不等同于实机渲染。
