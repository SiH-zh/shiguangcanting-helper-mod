# 日常助手1.2.1：修复字体偶发整页粗黑

日期：2026年11月9日（北京时间）。对应标签：`v1.2.1`。

1.2.1已由作者发布至[Steam创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3834109830)，优先推荐订阅安装。GitHub提供相同程序及对应源码，手动下载安装作为备选。

## 更新内容

- 固定使用`alibaba SDF`普通中文正文字体，必要时仅使用已知的`alibaba Dynamic SDF`后备字体，不再取场景里第一个文字控件的样式。
- 从字体基础材质复制模组专用材质，清除字面扩张、描边、阴影、发光等效果；保留字体图集、距离场刻度与裁剪参数。
- 正文显式使用普通字重；字面材质设为白色，保留文字控件自身的棕色正文、绿色正确答案和红色输入提示。
- 保留按钮绿色／黄色状态图、悬停、按下、禁用颜色及按钮原有显式粗体。
- 主窗口、答题浮窗、速度浮窗及数值输入统一使用修复后的初始化；停用或销毁界面时释放自有材质。
- 答题奖励结算、地鼠出现2秒后击打、移动倍率及开关设置保存逻辑保持原样。

## 问题原因

旧版按文字控件的资源枚举顺序选择第一份有效字体，并把该控件的共享材质用于整套助手界面。场景或其他模组的加载、打开顺序变化时，可能取到标题的扩张、厚描边或阴影预设，导致整页文字变粗黑。

本次改为固定正文资产和模组自有材质，避免继承任意标题的共享样式。游戏中的原始字体资产及其他界面的材质保持原样。

## 安装与更新

### 首选：Steam创意工坊订阅

打开[日常助手工坊页面](https://steamcommunity.com/sharedfiles/filedetails/?id=3834109830)点击“订阅”，等待Steam下载完成，进入游戏主菜单的“模组”启用。已经订阅的用户等待更新下载完成后，完整退出并重启游戏。

### 备选：GitHub手动安装

下载本页`DailyAssistant-v1.2.1.zip`，完整退出游戏，将包内`DailyAssistant`文件夹放入`游戏目录\Mods`。更新时将旧模组移到Mods目录之外备份，再完整替换。切换安装渠道时只保留一份启用的日常助手。

已有设置保存在`UserData\Current\DailyAssistant\state.json`，无需删除；初次安装默认关闭，此后保留用户开关及倍率。
