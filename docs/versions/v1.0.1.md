历史版本日期：2026年11月5日（北京时间）。公开归档标签：`v1.0.1`。

## 更新内容

- 将游戏右上角入口改为原创厨师帽地鼠图标，与原版任务入口区分。

尚无独立悬浮答案、2秒击打等待及移动速度调整。原版答题选项提示存在后续1.1.1修复的颜色标签显示及字体兼容问题。自动打地鼠每次启动默认关闭。

历史版本用于留档；如无兼容性回退需求，建议优先使用最新版。此前版本可能保留后续版本已修复的问题。
