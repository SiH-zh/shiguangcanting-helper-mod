# 日常助手 1.1.1：修复答题提示的颜色标签与缺字

历史版本日期：2026年11月5日（北京时间）。公开归档标签：`v1.1.1`。

## 更新内容

- 修复原版答题窗口将颜色标签当作普通文字显示的问题。
- 正确选项改为直接设置文字控件颜色，并追加纯文字“正确答案”提示。
- 移除可能缺字的勾号；字体不支持中文方括号时使用普通括号。
- 切换题目、关闭答题辅助或停用模组时恢复选项原有颜色。
- 保留独立悬浮答案、2秒击打等待、原版奖励结算和原创图标。

## 本版功能范围与注意事项

尚无移动速度调整；自动打地鼠每次启动默认关闭。此版本修复原版答题提示显示问题，完整界面表现仍应以所用游戏版本的实际运行结果为准。

历史版本用于留档；如无兼容性回退需求，建议优先使用最新版。此前版本可能保留后续版本已修复的问题。
