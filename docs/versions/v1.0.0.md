# 日常助手 1.0：首次发布：答题与打地鼠

历史版本日期：2026年11月5日（北京时间）。公开归档标签：`v1.0.0`。

## 更新内容

- 新增今日待答题目与正确答案查看，只处理当天尚未回答的题目。
- 支持自行答题时显示正确选项提示，或二次确认后自动提交剩余正确答案。
- 新增地鼠一键完成：二次确认后连续完成当天剩余次数，并汇总实际获得的板牙、新面具及集齐补偿。
- 新增自动打地鼠：在自己的餐厅等待地鼠自然刷新并自动击打。
- 奖励、成功次数、每日额度、面具规则均由游戏原版流程处理。
- 新增按存档及日期区分的收益记录、重复结算防护、跨日及换档保护；支持停止批量操作。
- 入口位于“我的餐厅”左侧，游戏内使用原版任务手账图标。

## 本版功能范围与注意事项

尚无独立悬浮答案或移动速度调整；尚未引入出现后等待2秒的击打策略。原版答题选项提示存在后续1.1.1修复的颜色标签显示及字体兼容问题。自动打地鼠每次启动默认关闭。

历史版本用于留档；如无兼容性回退需求，建议优先使用最新版。此前版本可能保留后续版本已修复的问题。

- `DailyAssistant-v1.0.0.zip`：可直接安装的完整模组包，包含动态库、图标、配置、对应版本源码、编译脚本、中文使用说明和许可证。
