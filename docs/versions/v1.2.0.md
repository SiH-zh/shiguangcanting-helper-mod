# 日常助手 1.2.0：移动速度微调与设置记忆

历史版本日期：2026年11月5日（北京时间）。公开归档标签：`v1.2.0`。

## 更新内容

- 新增“移动速度”页面及速度微调总开关，可分别调整服务员与客人的移动速度。
- 倍率范围1.0至10.0倍，最小调整幅度0.1倍；客人倍率包含普通客人和包房客人。
- 支持拖动滑块实时调整；右侧显示具体倍率，也可手动输入后按回车或离开输入框应用。
- 拒绝超出范围、不是0.1倍步长或格式无效的数值，保留之前的有效倍率并提示修改。
- 新增可拖动、可独立关闭的悬浮速度调整框，与主面板共享开关和倍率。
- 关闭速度微调后立即使用原版速度；仅在自己的餐厅影响对应角色的移动距离。
- 仅初次安装、尚无保存设置时全部功能默认关闭；之后保存并恢复答题辅助、自动打地鼠、速度微调开关及两类倍率。
- 保留悬浮答案、答题提示颜色修复、地鼠出现2秒后击打、原版奖励结算及原创图标。

## 本版功能范围与注意事项

新增速度界面及移动表现已交由用户手动验证，目前没有完整实机复测结论。游戏更新相关接口后可能需要适配；不承诺兼容全部后续游戏版本或其他修改同一逻辑的模组。
