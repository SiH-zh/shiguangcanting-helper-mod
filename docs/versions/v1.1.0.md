# 日常助手 1.1.0：悬浮答案与2秒击打等待

历史版本日期：2026年11月5日（北京时间）。公开归档标签：`v1.1.0`。

## 更新内容

- 新增“悬浮答案”按钮，独立显示今日待答题目、正确答案及剩余数量。
- 答案浮窗支持拖动标题栏及独立关闭，关闭主面板后仍可查看。
- 点击“自己答题”时，同时打开原版答题窗口和悬浮答案。
- 答题后自动刷新剩余内容；离开自己的餐厅、关闭辅助、跨日或换档时关闭浮窗。
- 自动模式与一键模式均改为每只地鼠初始化成功后，按游戏运行时间等待2秒再击打。
- 保留原版地鼠生命周期、自然刷新节奏和奖励规则，以及原创厨师帽地鼠图标。

## 本版功能范围与注意事项

原版答题窗口的选项提示可能直接显示颜色标签或缺字方框，1.1.1已修复；独立悬浮答案可用于查看答案。尚无移动速度调整，自动打地鼠每次启动默认关闭。

历史版本用于留档；如无兼容性回退需求，建议优先使用最新版。此前版本可能保留后续版本已修复的问题。
